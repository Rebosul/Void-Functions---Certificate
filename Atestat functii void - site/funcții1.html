Mai jos sunt afișate diferite moduri de a apela funcțiile void și care este diferența dintre ele.

void funcție(int a)

Funcția este apelată folosind o singură variabilă de tip număr.

void funcție(char a)

Funcția este apelată folosind o singură variabilă de tip caracter.

void funcție()

Funcția este apelată fară a folosi nicio variabilă. Asta înseamna că funcția va face întotdeauna exact aceleași operații.

void funcție(int v[100])

Funcția este apelată folosind un vector de variabile număr de dimensiune 100.

void funcție(int a,char b,int v[100])

Funcția este apelată folosind o variabilă de tip număr, o variabilă de tip caracter și un vector de variabile număr de dimensiune 100.

void funcție(int a,int &b);

Funcția este apelată folosind o variabilă de tip număr globală sau locală (număr care își va păstra valoarea în exteriorul funcției void) și o variabilă prin referință, care va păstra în exteriorul funcției orice modificare făcută prin funcție.
